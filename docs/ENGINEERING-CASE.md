# VOLT: Конфигуратор с одним источником состояния

Синхронизировать внешний вид велосипеда, цену, условный запас хода и ссылку на выбранную комплектацию.

AI-assisted учебный проект. Не коммерческий заказ.

## Архитектура
content/bike.js → чистые функции цены и дальности → состояние Configurator → SVG / итог / демоформа → URL.

## Производные значения
Цена считается из базовых 129 000 ₽, доплаты 4 000 ₽ за отделку и 18 000 ₽ за батарею. Отдельное состояние цены не хранится: оно выводится из выбранных опций.

## Честная модель дальности
Wh делятся на условный расход 6 / 8 / 11 Wh на км с коэффициентом рельефа 1 / 1,18 / 1,45. Это демонстрация зависимости, а не обещание характеристик реального велосипеда.

## Восстановление по ссылке
URL принимает только известные значения отделки, батареи, помощи и рельефа. Некорректные и повторяющиеся параметры безопасно возвращают значения по умолчанию. SVG использует useId для уникальных градиентов.

## Проверить
Изменение батареи обновляет цену и дальность; ссылка восстанавливает всю конфигурацию в новой вкладке. Несуществующее значение параметра не ломает страницу.

## Проверки
Модульные проверки цены, дальности и URL; браузерные сценарии конфигуратора, восстановления ссылки, ошибок формы и навигации.

## Ограничения
VOLT One — вымышленная модель. Нет физических испытаний, реальных спецификаций, покупки или бронирования. Демо-форма проверяет ввод, но ничего не отправляет.
